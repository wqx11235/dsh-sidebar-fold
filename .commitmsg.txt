0.7.1：修改包名后 web boot 崩溃（bundle 自声明 id 必须等于包名）

症状：改包名为 dsh-sidebar-fold-37 后启动报
  web boot: 1 entry did not activate / dsh-sidebar-fold-37: import failed
  renderer: client-modules: duplicate factory registration for dsh-sidebar-fold
原因：bundle 里 window.__ModuleLoader__.load({id}) 仍写旧名；模块系统按 manifest entry id（=包名）索引 factory，
     找不到就再执行一遍 bundle，于是重复注册。
修法：id 跟包名对齐（dsh-sidebar-fold-37）。
