Adds **dsh-sidebar-fold** — a sidebar tidy-up plugin for DSH.

**What it does**

- Collapses the plugin panel rows in the sidebar into a single last row ("More" / 「更多」).
- Hovering (120 ms) or clicking that row expands the list inline, underneath the row, pushing the workspace list down — not a floating popover.
- Right-clicking the row opens the plugin's own settings page, where you choose which panels stay in the sidebar instead of being folded.
- Rows are re-synced on every sidebar change, so newly installed or removed plugins are picked up automatically.

**Contributing-guide requirements**

- package.json declares a dsh.bundle manifest with a cordis.patch.yml that has an insert row.
- The repo carries the dsh-plugin topic.
- The repo is older than 1 day.

**Install source**

- v0.6.6 release ships a prebuilt dsh-sidebar-fold-0.6.6.tgz asset (preferred — no source build).
- The source repo works as the fallback.

**Notes**

- Client-only plugin: no host services, no network calls, no credentials.
- The UI is DOM-based because the host has no official API for an inline hover expansion; the README states that limitation explicitly.
